For ANY timing recommendation, check (in order):

### **Layer 1: Day Quality**
- [ ] Chandra Bal (Moon strength) - "Is today good?"

- If Moon is weak → Day is not suitable

### **Layer 2: Year/Month Context**
- [ ] Sun position - "What month quality?"
- [ ] Moon position - "What month/day quality?"

### **Layer 3: Panchang (5 Limbs)**
- [ ] Tithi % (lunar day)
- [ ] Vaar % (day of week)
- [ ] Karana % (half-tithi)
- [ ] Nakshatra % (lunar mansion)
- [ ] Yoga % (planetary combination)

### **Layer 4: Hourly Matching**
- [ ] Hora (1 hour lord) - percentage
- [ ] Upa-hora (5-7 min lord) - fine-tuning

### **Layer 5: Navtara (Star Position)**
- [ ] Current Nakshatra
- [ ] Benefic/Malefic classification
- [ ] Adjustment factor

### **Layer 6: KP System**
- [ ] House lord (Nakshatra)
- [ ] Sub-lord (Nakshatra) - TEST of result
- [ ] Sub-sub-lord position

### **Layer 7: Dasha Analysis (MOST CRITICAL FOR DAILY EVENTS)**
- [ ] **Dasha** (major period - years)
- [ ] **Antardasha** (sub-period - months)
- [ ] **Prayantara Dasha** (sub-sub-period - weeks)
- [ ] **Shooksma Dasha** (sub-sub-sub-period - DAYS) ← **DECIDES EVENT**

### **Layer 8: Gochar (Current Transits)**
- [ ] Which planets active today
- [ ] Support/obstruction factor

## **KEY PRINCIPLES**

1. **Shooksma Dasha DECIDES THE EVENT**
   - Most granular level (daily periods)
   - Determines if event happens TODAY or NOT

2. **Moon Strength DECIDES DAY QUALITY**
   - Chandra Bal = Day goodness
   - Strong Moon = Auspicious day
   - Weak Moon = Inauspicious day

3. **Sun DECIDES MONTH QUALITY**
   - Sun in each rashi for ~30 days
   - Defines the month's nature

4. **Layer Stacking = Confidence %**
   - Each layer adds/subtracts percentage
   - Final % = Combined all layers
   - Can predict down to 1-minute accuracy
