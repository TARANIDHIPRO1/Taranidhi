## PART 2: DUAL-LAYER SCORING ARCHITECTURE

### Layer 1: UNIVERSAL SCORING (No Kundali Needed)
**Weight: 40% of total score**

Applicable to all users, no birth chart required.

#### Criteria:
| Criterion | Points | Rule | Source |
|-----------|--------|------|--------|
| **Abhijit Muhurta** | +25 | Solar noon ±24 min | Muhurta Chintamani 1.8 |
| **Vijaya Muhurta** | +20 | 8th daytime segment | Dharmasindhu |
| **Brahma Muhurta** | +20 | Sunrise −96 to −48 min | Muhurta Chintamani 1.4 |
| **Sarvartha Siddhi Yoga** | +25 | Weekday + Nakshatra match | Dharmasindhu |
| **Guru/Ravi Pushya** | +35 | Thu+Pushya OR Sun+Pushya | Muhurta Chintamani |
| **Pushkara Navamsha** | +20 | Moon in specific navamsha | Classical Panchang |
| **Auspicious Tithi** | +15 | Shukla 2,3,5,7,10,11,13 | Classical Panchang |
| **Auspicious Nakshatra** | +10 | Purpose-specific nak | Category-defined |
| **No Rahu Kaal** | +15 | Outside Rahu window | Standard Panchang |
| **No Yamghanda** | +10 | Outside Yamghanda window | Panchang traditions |
| **No Gulika Kaal** | +10 | Outside Gulika window (medical only) | Panchang traditions |
| **Hora Match** | +20 | Planet hora benefic for purpose | Hora Ratna |
| **No Durmuhurta** | +10 | Avoid weekday-specific inauspicious | Muhurta Chintamani |
| **Inauspicious Tithi** | -30 | Amavasya, 4,6,8,9,12,14,15 | Panchang texts |
| **Vishti/Bhadra Karana** | -20 | If active | Karana Dosha |
| **Panchaka Dosha** | -25 | If active (specific naks) | Panchaka rules |

**Calculation:**
```
UNIVERSAL_SCORE = SUM(matching criteria) / MAX(possible) × 100
MAX possible = ~220 points
```
