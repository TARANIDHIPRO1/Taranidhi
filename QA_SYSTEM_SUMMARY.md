## **How It Works**

### **When implementing a new feature:**

```
STEP 1: RESEARCH (Using FACT_CHECK_ENGINE.md)
   └─ Find classical source
   └─ Verify against 10 test cases
   └─ Document in FACT_CHECK_ENGINE.md
   └─ Wait for Naveen approval

STEP 2: ALGORITHM DESIGN (Using ERROR_PREVENTION_PROMPT.md)
   └─ Write pseudo-code
   └─ Test pseudo-code manually
   └─ Define edge cases
   └─ Prepare test data

STEP 3: IMPLEMENTATION (Using ERROR_PREVENTION_PROMPT.md)
   └─ Follow 6 golden rules (no magic numbers, validate inputs, etc.)
   └─ Add detailed comments
   └─ Add error handling
   └─ Small, focused commits

STEP 4: TESTING (Using QUALITY_ASSURANCE_PROTOCOL.md)
   └─ Run unit tests immediately (same day)
   └─ Run integration tests
   └─ Run edge case tests
   └─ Check performance
   └─ Verify 100% pass rate

STEP 5: DEPLOYMENT (Only after ALL tests pass)
   └─ Get Naveen approval
   └─ Deploy to production
   └─ Monitor continuously
```
